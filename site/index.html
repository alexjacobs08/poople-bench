Poople Bench 💩

Can LLMs one-shot the daily Poople word ladder? Models get the start word and the legal word list, and must output a complete ladder to POOP in a single response — scored against the provable optimum (par).

Method. One-shot, open book: each model receives the day's start word plus the full 2,398-word legal list (harvested from the game itself) and returns a whole ladder in one response — no tools, no feedback, k=3 trials daily (k=1 for backfilled days), provider-default sampling. "Effort" is the pinned reasoning-effort setting (models without a medium tier run their middle one; blank = no reasoning parameter). Score = par ÷ steps for a legal ladder, 0 for an illegal one; par is verified independently by BFS. Costs are exact per-request charges reported by OpenRouter. API failures are excluded from scores. Daily rankings are entertainment; trust the rolling window. Source & data: github.com/alexjacobs08/poople-bench.
